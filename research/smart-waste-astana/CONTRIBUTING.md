# Разработка

1. Создать задачу в GitHub Issues с ожидаемым поведением и критериями приёмки.
2. Создать ветку `feature/short-name` от main.
3. Изменять код небольшими осмысленными коммитами.
4. Выполнить тесты, demo и tools/build_release.py из папки модуля.
5. Открыть pull request; описать проблему, результат и проверки.
6. Проверить GitHub Actions до объединения изменений.

Не добавлять персональные данные и ключи доступа. Данные исследований должны иметь
документированное происхождение. Смена алгоритма требует сравнения с baseline на holdout.
