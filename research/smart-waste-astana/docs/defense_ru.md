# Демонстрация преподавателю

1. Открыть README и показать связь модуля с темой диссертации.
2. Выполнить `py -3 main.py demo`, открыть results/dashboard.html.
3. Показать 24 контейнера, 8 выбранных и 2 рейса для seed=42.
4. Объяснить: данные синтетические, расстояния по прямой, агенты с правилами и алгоритмами.
5. Выполнить `py -3 main.py demo --agents 2 --output results_basic` и сравнить режимы.
6. Выполнить `py -3 -m unittest discover -s tests -v`.
7. Открыть историю Git, Issues и CI/CD в GitHub. Показать успешный run и скачиваемый ZIP.

Короткий спич:

«Я разработал научный модуль для анализа данных о заполненности контейнеров.
В минимальном режиме работают два агента: анализ и определение приоритетов.
Полная версия включает ещё прогноз, построение рейсов и оценку результата.
Агенты обмениваются данными через типизированный контекст, поэтому систему можно расширять.
Прогноз оценивается на последней дате, которую алгоритм не видел при обучении.
Для сравнения используется базовый метод — повторение последнего наблюдения.
GitHub Actions проверяет программу на Windows и Linux и доставляет архив после тестов.
Демонстрационные данные синтетические; следующий этап исследования — реальные измерения и дорожные маршруты».

Почему нет нейросети? Assignment 3 проверяет организацию разработки и интеграции.
Объяснимые алгоритмы достаточны для небольшого научного модуля; нейросеть можно добавить как новый агент.
Почему unittest? Он встроен в Python и позволяет запускать все проверки без pip.
Что такое CD здесь? Доставка проверенного ZIP пользователю через Actions artifact или GitHub Release.
Почему нельзя заявить сокращение затрат города? Нет реальной телеметрии и дорожной модели.
