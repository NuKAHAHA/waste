# Происхождение демонстрационных данных

Файл `data/astana_synthetic.csv` создан `generate_demo(seed=42, bins=24, days=7)`.
Период: 2026-10-01..2026-10-07. Координаты случайны внутри прямоугольника
51.10..51.18 N, 71.37..71.49 E; это условная география Астаны.
Названия районов используются как демонстрационные подписи, не проверяются по границам.
Контейнеры, телеметрия и депо вымышлены. Источник не является муниципальным датасетом.

Рост генерируется с небольшим случайным возмущением и фиксированным seed.
Процент заполненности ограничен 100; уменьшения после вывоза не моделируются.
Ёмкости выбираются из 1.1, 2.5, 4.0 м³. Параметры генератора доступны в коде.
Данные распространяются вместе с модулем по MIT.

Для реальных исследований нужно согласовать права на данные, проверить координаты,
описать измерительные устройства и разделить записи на интервалы между вывозами.
Оценка на этом синтетическом наборе подтверждает работу программы, а не эксплуатационный эффект.
